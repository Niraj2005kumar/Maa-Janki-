# Maa Janki Showcase

Create a premium, modern, highly responsive business website for a local tiles and marble showroom named:

"MAA JANKI TILES & MARBLES"

Location:

Saranda, Kharkhari, Jharkhand – 825324

Business Type:

Tiles, Marbles & Building Material Store

Main Goal:

The website should generate real local customers from Google Search/Google Maps and convert visitors into WhatsApp enquiries, phone calls, and physical showroom visits.

IMPORTANT:

This is NOT an e-commerce website. Do not add unnecessary online payment/cart/checkout features.

TECHNOLOGY:

Use only:

- HTML5

- CSS3

- Vanilla JavaScript

Do NOT use:

- React

- Vue

- Angular

- Bootstrap

- Tailwind CSS

- jQuery

- Any frontend framework

The website must be lightweight, fast-loading, SEO-friendly and easy to maintain.
